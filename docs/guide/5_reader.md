# Reader

You use the model to answer questions; you change nothing.

## What you can ask

- **Browse** elements by type, state, work package or attribute.
- **Open an element:** what it relates to, both ways, and the links to its own
  documentation.
- **Impact:** what depends on an element, and what it depends on.
- **Target state:** what a work package changes, drawn.
- **Ask** a question in words; the answer names the elements it rests on.

## How to read what you find

- **A relationship has a direction.** "Processes", "is stored in" and "serves"
  each read one way; the element page shows both.
- **Target states are intentions.** They say what is planned, not what is true
  today; the current state says that.
- **Detail below the enterprise level is behind the links.** A system's inside
  is not in the model; its page is linked from the system.
